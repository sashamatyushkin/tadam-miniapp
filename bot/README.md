# Бот «Та-дам»

Бот: **@tadamapp_bot**

## Что уже настроено через Bot API
- кнопка меню в чате → открывает Mini App;
- в меню команд только `/start` и `/help`;
- скрытые, но рабочие команды `/terms`, `/support`, `/paysupport` (нужны для ботов с платежами);
- описание и краткое описание бота.

## Запуск

Бот больше не отдельный процесс — он часть сервера (`server/`), потому что делит с ним базу
и планировщик напоминаний:

```bash
cd server && npm start
```

Токен лежит локально в `server/.env` (файл в .gitignore, в репозиторий не попадает).

Сейчас это long polling: бот работает, только пока запущен процесс. Для боевой версии нужен
хостинг и webhook с secret token.

## Напоминания

шлёт сообщение за 14/7/3/1 день до события. Подробности — в `server/README.md`.
