# Выкладка «Та-дам» на сервер

Приложение состоит из двух частей:

| Часть | Что это | Где живёт сейчас | Где должна жить |
|---|---|---|---|
| Фронтенд (Mini App) | Статичные файлы: `index.html`, `styles.css`, `js/`, `assets/` | GitHub Pages | GitHub Pages можно оставить, или любой хостинг статики на своём домене |
| Backend | `server/` — API, бот и напоминания в одном процессе Node | Только локально | VPS или контейнерный хостинг с постоянным диском |

## 1. Что подготовить заранее

- **VPS** с Node.js ≥ 22.5 или Docker. Хватит 1 vCPU / 1 ГБ RAM. Если собираем персональные
  данные граждан РФ (профиль: имя, пол, дата рождения) — сервер должен быть в России (152-ФЗ).
- **Домен** и **HTTPS** — Telegram открывает Mini App только по https. Например:
  `app.<домен>` для фронтенда и `api.<домен>` для backend.
- **Новый токен бота**: токен уже пересылался в переписке, перед запуском его стоит
  перевыпустить в @BotFather (`/revoke`).

## 2. Backend

```bash
cd server
cp .env.example .env     # заполнить: BOT_TOKEN, WEBAPP_URL, ALLOWED_ORIGINS
```

**Вариант А — Docker**

```bash
docker build -t tadam-server server/
docker run -d --name tadam --restart unless-stopped \
  --env-file server/.env -p 127.0.0.1:8787:8787 \
  -v tadam-data:/app/data tadam-server
```

Том `tadam-data` — это база. Без него данные пропадут при пересборке.

**Вариант Б — напрямую**, под systemd или pm2: `cd server && npm start`.

**HTTPS перед API** — через Caddy (сам получает сертификат):

```
api.<домен> {
  reverse_proxy 127.0.0.1:8787
}
```

Проверка: `https://api.<домен>/api/health` → `{"ok":true}`.

Важно: процесс должен быть **один**. Бот работает через long polling — два экземпляра
будут отнимать друг у друга сообщения.

## 3. Фронтенд

1. В `js/config.js` вписать адрес API: `const PROD_API_BASE = 'https://api.<домен>';`
2. Если фронтенд переезжает на свой домен — в `.env` сервера обновить `WEBAPP_URL` и `ALLOWED_ORIGINS`.
3. `python3 tools/bump.py` — проставляет версии файлов, чтобы Telegram не показывал старый кеш.
4. Залить файлы (кроме `server/`, `bot/`, `tools/`) на хостинг статики.

## 4. Telegram

- @BotFather → `/setmenubutton` → адрес фронтенда.
- @BotFather → `/newapp` — именованный Mini App на боевом домене. Короткое имя вписать
  в `js/config.js` → `TELEGRAM.appName`: тогда ссылки-намёки будут открывать приложение сразу, а не через бота.
- Описание и аватар бота: `/setdescription`, `/setabouttext`, `/setuserpic`.

## 5. Админка

Адрес: `https://api.<домен>/admin`. Логин и пароль — `ADMIN_USER` и `ADMIN_PASS` в `.env`
(пока они не заданы, админка выключена). Пароль — длинный и случайный.

| Раздел | Что там |
|---|---|
| Обзор | Выводы «Коротко о главном», новые пользователи по дням, откуда приходят, тарифы, пол, возраст, кому дарят, интересы, популярное в вишлистах, подарки мечты, призы колеса |
| Пользователи | Все профили с поиском. В профиле — вишлисты, даты, приглашённые друзья, выдача и отзыв доступа (неделя / год / навсегда) |
| Промокоды и друзья | Создание промокодов со ссылкой `t.me/<бот>?start=p_<код>`, сколько человек пришло и сколько купили; кто сколько друзей пригласил |
| Заявки UGC | Одобрить (premium на год), подтвердить 100 000 (навсегда) или отклонить — автору приходит сообщение от бота |
| Идеи подарков, Сторис, Друзья бренда | Добавить, изменить, удалить |

Изменения контента появляются у пользователей при следующем открытии приложения.
Второму администратору пока выдаётся тот же логин и пароль.

## 6. Перед тем как пускать реальных пользователей

- `ALLOW_TEST_PAYMENTS=0` в `.env` (по умолчанию так и есть).
- Подключены платежи (см. аудит): пока их нет, кнопка «Оплатить» открывает premium без списания.
- Опубликованы политика конфиденциальности и оферта, в профиле — согласие на обработку данных.
- Настроено ежедневное резервное копирование `server/data/tadam.sqlite`.

## Служебный режим

Кнопка «Сбросить всё до первого запуска» в Настройках видна только тестировщикам:
открыть приложение по ссылке с `?debug=1`. Выключить — `?debug=0`.
